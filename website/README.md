# Murmur — landing page

Marketing site for [Murmur](https://github.com/Yatishgrandhe/murmur), the free voice-to-text Mac app.

React + TypeScript + Vite + Framer Motion. No database, no backend.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static files in dist/
```

Ten full-screen sections that alternate black, light, white and one cobalt section: desktop hero with a live dictation loop, mess → message with a style picker, 3D shortcut keys, "Hey Murmur", windows cascade, AI picker, Dictionary + History windows, privacy, install (macOS / Windows, OS auto-detected), FAQ + download.
